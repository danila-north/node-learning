# notes-api

REST API для заметок: можно создавать, читать, изменять и удалять заметки по HTTP.
В проекте есть проверка API-ключа, валидация, обработка ошибок, разделение на слои
(routes → controllers → services) и хранение данных в файле.

## Стек

- Node.js
- Express
- zod

## Запуск

1. Установить зависимости: `npm install`
2. Создать в корне репозитория файл `.env` по примеру `.env.example`:
   ```
   API_KEY=твой-секретный-ключ
   ```
3. Запустить сервер: `npm run notes-api`

Сервер запускается на `http://localhost:3000`.

## Авторизация

Каждый запрос должен содержать заголовок с ключом из `.env`:

```
x-api-key: твой-секретный-ключ
```

Без ключа или с неверным ключом сервер отвечает `401 Unauthorized`.

## Эндпоинты

| Метод  | Путь         | Что делает       | Ответ                         |
| ------ | ------------ | ---------------- | ----------------------------- |
| GET    | `/notes`     | все заметки      | 200                           |
| GET    | `/notes/:id` | одна заметка     | 200 или 404                   |
| POST   | `/notes`     | создать заметку  | 201, 400 при ошибке валидации |
| PUT    | `/notes/:id` | изменить заметку | 200, 400 или 404              |
| DELETE | `/notes/:id` | удалить заметку  | 204 или 404                   |

Тело для `POST` и `PUT`:

```json
{ "text": "текст заметки" }
```

Текст обязателен, от 1 до 500 символов.

## Хранение данных

Заметки хранятся в файле `data/notes.json` и сохраняются после перезапуска сервера.
