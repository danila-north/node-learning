## this
**Зачем:** чтобы один метод работал с разными объектами.

```js
const user = { name: "Данила", greet() { console.log(this.name); } };
user.greet(); // Данила — перед точкой user

const fn = user.greet;
fn(); // undefined — точки нет, this потерялся
```

## Стрелочные функции и this
**Зачем:** у стрелки нет своего `this`, она берёт его снаружи. Удобно в колбэках внутри методов.
**Правило:** для методов объекта — обычная функция, для колбэков внутри методов — стрелка.

```js
const timer = {
  name: "Таймер",
  start() {
    setTimeout(() => console.log(this.name), 1000); // Таймер
  },
};
```

## Прототип
**Зачем:** общее хранилище методов, чтобы не копировать их в каждый объект.
**Цепочка прототипов:** нет свойства в объекте → JS ищет в прототипе → нигде нет → `undefined`.

```js
const obj = { a: 1 };
obj.a;        // 1 — своё свойство
obj.toString; // нашлось в прототипе
obj.xyz;      // undefined — нет нигде
```

## super
**Зачем:** попросить родителя выполнить свою часть конструктора, чтобы не копировать его код.
**Правило:** вызывать первой строкой, до любого `this`.

```js
class User {
  constructor(name) { this.name = name; }
}
class Admin extends User {
  constructor(name, role) {
    super(name);      // User записывает имя
    this.role = role; // Admin дописывает роль
  }
}
```

## Замыкание
**Зачем:** функция помнит переменные снаружи, где была создана. Так делают приватные данные.

```js
function createCounter() {
  let count = 0;
  return () => ++count;
}
const counter = createCounter();
counter(); // 1
counter(); // 2 — count помнится
```

## Event loop
**Порядок:** синхронный код → промисы (`.then`, `await`) → `setTimeout`.

```js
console.log("A");
setTimeout(() => console.log("B"), 0);
Promise.resolve().then(() => console.log("C"));
console.log("D");
// A D C B
```

## const и объекты
**Правило:** `const` запрещает перезаписать переменную, но не менять содержимое.

```js
const user = { name: "Данила" };
user.name = "Петя"; // можно — меняем содержимое
user = {};          // ошибка — перезапись
```

## Falsy
**Шесть значений, которые в условии дают false:**
`false`, `0`, `""`, `null`, `undefined`, `NaN`. Всё остальное — truthy, даже `[]` и `{}`.

## Set и Map
- **Set** — набор без повторов. Убрать дубли: `[...new Set(arr)]`
- **Map** — словарь «ключ → значение»: `set` положить, `get` достать, `has` проверить.

```js
[...new Set([1, 1, 2])]; // [1, 2]

const stock = new Map();
stock.set("mouse", 20);
stock.get("mouse"); // 20
```

## JSON
- `JSON.stringify(obj)` → **строка** (string-ify = сделать строкой). Чтобы отправить или сохранить.
- `JSON.parse(str)` → объект. Кривой JSON ломает программу — оборачивать в `try/catch`.

## Деструктуризация
**Слева** — новые переменные, **справа** — откуда берём.

```js
const { price: cost, discount = 0 } = product; // переименование и значение по умолчанию
const [first, second] = arr;
```

## Spread и rest
- **Spread** (справа от `=`) — высыпать: `[...a, ...b]`, `{ ...obj }`
- **Rest** (слева от `=`) — собрать остаток: `const [main, ...rest] = arr`
- **Что позже — то и выигрывает:** `{ ...a, x: 5 }` → `x` будет 5

## Копирование
- `b = a` → одно и то же под двумя именами
- `{ ...a }` / `[...a]` → поверхностная копия: вложенные объекты общие
- `structuredClone(a)` → глубокая копия: всё отдельно

## Промис
**Зачем:** обещание, что результат появится позже — успех (`resolve`) или ошибка (`reject`).
**Состояния:** pending → fulfilled или rejected.

## await
**Зачем:** остановить функцию, пока промис не выполнится, и получить результат.
**Без await** в переменной будет сам промис, а не результат.

```js
const a = getProduct(1);       // промис (ещё не готов)
const b = await getProduct(1); // готовый товар
```

## Promise.all и родственники
- `all` — все сразу, параллельно. Упал один — падает всё.
- `allSettled` — ждёт всех, никогда не падает, пишет статус каждого.
- `race` — гонка: кто первый закончил.
- `any` — первый **успешный**.

**Правило:** задачи не зависят друг от друга → `Promise.all`. Зависят → `await` по очереди.
