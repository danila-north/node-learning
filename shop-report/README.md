# Shop Report

Консольная программа на Node.js, которая загружает товары
из DummyJSON API и выводит отчёт по магазину.

## Что умеет
- загружает товары и категории параллельно (Promise.all)
- считает среднюю цену, топ дорогих и топ по рейтингу
- показывает товары, которые заканчиваются
- считает количество товаров по категориям
- обрабатывает ошибки сети и API

## Технологии
Node.js, ES-модули, fetch, async/await

## Запуск
node main.js
